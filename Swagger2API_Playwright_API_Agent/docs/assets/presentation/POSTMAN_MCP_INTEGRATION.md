# 📬 Postman MCP Server Integration Guide

This guide explains how to connect your **Swagger2API AI Agent** and its generated Postman collections directly to the **Postman MCP (Model Context Protocol) Server**.

Official Postman Reference: [Postman MCP Server: Connect AI Agents to Your API Workflows](https://www.postman.com/product/mcp-server/)

---

## 🌟 What is Postman MCP Server?

The Postman Model Context Protocol (MCP) server allows AI agents (like Antigravity, Claude, or Cursor) to directly:
1. Discover existing Postman workspaces and collections.
2. Synchronize, upload, and update API collections autonomously.
3. Trigger automated test runs via Newman or the Postman Cloud runner.
4. Read real-time test execution results and generate insights.

---

## 🛠️ Step 1: Configure Postman MCP in your IDE / Agent

Add the Postman MCP configuration to your MCP config (`mcp_config.json`):

```json
{
  "mcpServers": {
    "postman": {
      "command": "npx",
      "args": [
        "-y",
        "@postman/mcp-server"
      ],
      "env": {
        "POSTMAN_API_KEY": "PMAK-your-postman-api-key-here"
      }
    }
  }
}
```

> **Note**: Obtain your API key from [Postman Account Settings > API Keys](https://go.postman.co/settings/me/api-keys).

---

## 🔄 Step 2: Collection Workflow (Positive then Negative Sequence)

The collections generated by Swagger2API follow Postman and SDET best practices:

1. **`📁 1. Positive Scenarios`**:
   - Executes Happy Path CRUD requests in order: `POST` (create) ➡️ `GET` (fetch) ➡️ `PUT/PATCH` (update) ➡️ `DELETE` (clean up).
   - Injected tests assert status `200/201/204`, response latency (< 1500ms), and schema validity.

2. **`📁 2. Negative Scenarios`**:
   - Tests boundary edge cases, non-existent entity IDs (e.g. `999999999`), and malformed bodies.
   - Injected tests assert proper error status codes (`400`, `404`, or `422`).

---

## 🤖 Step 3: Prompting your Agent via Postman MCP

Once the Postman MCP server is running, you can ask your AI Agent:

> *"Sync the generated `collection.json` to my Postman Workspace 'API Automation Squad' and run the positive scenarios folder."*

The Postman MCP tools will:
- Call `postman_create_collection` or `postman_import_collection`.
- Return the live collection UID and URL.
- Allow running and debugging directly within your Postman desktop client or web workspace!
