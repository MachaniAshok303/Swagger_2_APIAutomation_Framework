How It Works: Clean 4-Tier Framework Architecture

TIER 1: CLIENT LAYER (baseApiClient.ts, tokenManager.ts, <resource>Client.ts)

HTTP engine wrapper, header injection, in-memory token caching, latency recording & secret masking.

TIER 2: SERVICE LAYER (<resource>.service.ts, authManager.ts)

Encapsulates business operations, payload synthesis, and domain logic away from test specs.

TIER 3: FIXTURES & DATA (api.fixture.ts, dataGenerator.ts, <resource>.model.ts)

Injects services via Playwright fixtures; manages strongly-typed models & dynamic test data generators.

TIER 4: TEST SUITES (smoke/, regression/, contract/, e2e/, negative/, security/)

Independent test specs covering CRUD, AJV schema verification, dynamic ID correlation & OWASP security.
